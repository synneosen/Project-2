## Description

This project implements a feed-forward neural network with backpropagation.
The network is applied to regression on the one-dimensional Runge function and
compared with OLS, Ridge and Lasso regression. It is also applied to MNIST
classification and compared with logistic regression.

## Installation

The notebooks were prepared with Python 3.11.4. From the repository root,
install the dependencies with:

```bash
py -3.11 -m pip install -r requirements.txt
```

Part E reads MNIST from `data/mnist.npz`. Download the file from
<https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz> and
put it in `data/`. The data set is not tracked by Git.

## Running the notebooks

Open a notebook in `Code/`, select the Python 3.11 environment as kernel and
use **Run All**. The working directory must be `Code/`. The notebooks use the
shared modules in `Code/` and do not depend on each other's output.

## Repository layout


## Python modules

| Module | Description |
|---|---|
| `data.py` | Runge data generation and splitting, regression scaling, MNIST loading and one-hot encoding. |
| `nn.py` | Neural network with activations, cost functions, backpropagation, prediction and training. |
| `optimizers.py` | Gradient descent, RMSprop and Adam. |
| `metrics.py` | Accuracy. |
| `plotting.py` | Heatmap and confusion-matrix plotting. |
